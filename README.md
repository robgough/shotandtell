# Shot and tell

A macOS screenshot tool for talking to AI about pictures.

Capture a region, a window or a screen; point at things with numbered markers and
describe them; censor what shouldn't be seen. You get back one image: the screenshot on
a background, with a numbered legend beside it — so "the heading in ① is too big" means
something to a model that can only see pixels.

Menubar app with a Dock icon. Click the Dock icon or pick *New Capture* to start.

macOS 26+. Mac App Store. Free.
